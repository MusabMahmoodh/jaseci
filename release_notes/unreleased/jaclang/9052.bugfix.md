- **Fix: a profile's `[apps.<name>]` table now reaches the app definitions**: `jac.<profile>.toml`, `jac.local.toml` and `[environments.<name>]` parsed an `[apps]` table and discarded it, so an overlay could retune `[scale.gateway]` but not `[apps.worker_sv.scale]` in the same file; both merge paths now deep-merge the overlay onto the base `[apps]` table and re-parse it, so the merged table gets the same validation the base one does. An overlay that declares `[apps]` against a `jac.toml` that has none is now rejected instead of silently ignored.
