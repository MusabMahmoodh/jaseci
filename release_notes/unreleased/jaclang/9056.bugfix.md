- **Stale-runtime cleanup no longer fails the run**: pruning older runtime caches after a successful first-run setup is now best effort, so a file that resists removal (for example bytecode another `jac` process is writing into a shared `XDG_CACHE_HOME`) leaves the stale tree for a later run instead of aborting the invocation with `Uncaught exception: rmtree: could not remove ...`.
